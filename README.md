# AI News Daily – n8n Automation

An AI-powered workflow automation project built using n8n that automatically collects AI and technology news, summarizes the articles using Generative AI, and delivers the results through a structured HTML email.

## Workflow

RSS Feeds
   ↓
News Data Collection
   ↓
Data Processing
   ↓
Generative AI
   ↓
Article Summarization
   ↓
HTML Formatting
   ↓
Email Delivery

## Technologies Used

- n8n
- Generative AI
- RSS Feeds
- HTML
- Email Automation

## Key Features

- Automatically collects news from RSS feeds
- Processes incoming news data
- Generates AI-powered summaries
- Formats the results into an HTML email
- Automates the complete news delivery process

## How It Works

The workflow starts by reading news articles from RSS feeds. The collected information is processed and passed to a Generative AI model to generate concise summaries. The results are then formatted into an HTML-based email and delivered automatically.

## Project Workflow

The complete n8n workflow is available in:

`workflow/ai-news-daily.json`

The workflow can be imported into an n8n instance and configured with the required credentials.
